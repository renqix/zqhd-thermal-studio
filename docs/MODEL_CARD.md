# 第12版Tiny模型与外轮廓

当前模型为 `compact12_weak02`，Tiny revision5。14维输入→12 ReLU→8 ReLU→4子像素残差，共320参数、约303104乘加/32×32帧；INT8权重、INT32偏置和缩放常量共404字节，不含代码与显示缓存。

输入包括3×3中心差值、距离2点的四向取样，以及全图二阶差分噪声提示。输出为双线性基线上的有限残差，保持原3×3邻域限幅；孤立弱热点/冷点旁路残差。原生探头仍为32×32，输出插值不增加真实测温点。

`models/tiny/student-int8.npz`、`student-float.npz`和`tiny_weights.h`对应当前部署权重。第12版继续使用第9版权重；后续弱目标候选扩大复核后存在退步，因此没有部署。不将候选训练收益写成实装效果。

当前权重训练参考了实机噪声统计，原始采样与私有训练集不公开；当前公开包不提供完整训练复现流程。历史第3版合成数据、权重与训练记录保存在 `models/tiny/legacy-v3/`，`tools/train_tiny.py`只操作该目录，其分数不能作为当前模型结果。见[历史模型卡](MODEL_CARD-V3.md)。

背景降噪是本帧空间处理，滑块0～100，默认35；提高强度可能平滑弱纹理。外轮廓在实际温度上估计主导冷热区域，过滤小区域后只描与外部背景相邻的边缘。它不使用手动显示温区，不描内部孔洞；只有主要冷热方向的区域会被勾线。弱温差、小目标或几乎填满画面的目标可能不描线，这不是可见光物体识别。

热图、MIN/MAX和点测温仍取原始矩阵的对应路径；轮廓与Tiny只处理显示副本，不增加历史帧。Tiny热图本身会受到显示温区归一化影响，映射一致性保证只针对轮廓。

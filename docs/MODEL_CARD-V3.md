# Tiny模型能力与局限

## 模型区别

- Mac教师：Saafke EDSR TensorFlow ×2，自然图像DIV2K预训练，约37MiB，OpenCV CPU推理。不是热成像专用网络。
- MCU学生：3×3邻域与中心的差值→16 ReLU→8 ReLU→4子像素残差；332个参数，每32×32帧约311296乘加。INT8权重、INT32偏置、Q16缩放，总模型常量428字节，不含推理代码和约9.5KiB工作缓存。
- 学生用双线性基线加残差生成64×64，再缩放到236×236；限制残差和邻域输出范围。没有新增真实测温点。

## 数据与训练

360个合成训练热场、50验证、80测试，按整幅场景分离。目标为25% EDSR输出 + 75%已知合成真值；采用边缘、平滑热源、噪声等模拟结构。NumPy训练，权重和记录已包含。原始实验另观察32帧同一真实视角，它们不构成独立场景数据集，也不在公开包中。

公开的 `models/tiny/legacy-v3/dataset.npz` 只有合成输入/目标/真值。运行 `web/.venv/bin/python tools/train_tiny.py` 会覆盖学生模型实验输出，请在分支或副本中做。脚本加载公开数据重训时随机数消耗路径与最初生成数据时不同，因此不保证重训权重逐字节相同；发布权重为原实验固定检查点。更换权重后必须重测定点一致性、延迟和真实场景。

仅说明在这组模拟退化上有改善，不能证明真实温度分辨率、测温精度提高或优于所有现有算法。自然图像教师可能产生假纹理，学生也可能继承偏差；局部限幅并不能排除全部伪影。

## 实测边界

Mac原实验：EDSR含着色/JPEG中位约82ms，原始/增强约7.8fps；实时保边约13.3ms。仅代表开发机器和当时状态，非普遍保证。

设备Tiny渲染约45.5ms；一次滤波3、镜像关闭快照总处理约55.4ms、采样6.86fps。对比采样过程中滤波/镜像被切换，因此不能直接比较Tiny/L3差值；额外20ms目标尚未严格同配置验证。

原整数推理69组282624点与NumPy逐点一致，并经过地址/未定义行为检查。固件测温、MIN/MAX数字与触点值仍取原始温度，不取网络预测。

优先共创方向：更多独立真实场景、细小热点保真、移动目标拖影、INT8运行时优化、固定条件性能对比。无需进一步超频。

# 第12版外轮廓试用版

日期：2026-10-11。标签：`v12.0.0-public.1`，预发布。

相较首个公开版，新增背景降噪滑块及轮廓开关，更新320参数Tiny模型与有限次数探头启动重试，简化图像选项。针对内部碎线干扰，将梯度描边改为主要温差区域的外边界。算法参考OpenCV只取外层轮廓的思路，设备运行的是固定内存整数实现，没有链接OpenCV。

## 使用

- 从屏幕底部上滑进入设置，图像页的“轮廓”开关控制白线叠加，重启默认关闭。
- 降噪页的“背景降噪”滑块范围0～100，默认35。强度越高背景越平滑，也可能减弱细纹理。
- 开关、滑块等参数只保存在RAM，重新上电恢复默认值。
- Mac工作台同步支持轮廓与背景降噪控制；旧固件缺少相应状态字段时控件禁用。

## 验证范围

公开源代码主机测试包括：恒温无轮廓，80组场景×4映射范围与独立参考一致；冷暖主体内部纹理和孔洞不描线，外轮廓保持；接触画面边缘的主体及孤立坏点安全。检查使用地址与未定义行为检测。

本地系统字体版第12版已核验写入、启动、开关、两种插值与两种映射的回读；直接串口连续检查121.6秒、117个状态样本，采样序号87→1031，传感器及触摸无错误。背景降噪35时总处理耗时中位数：轮廓关闭58.40ms，开启64.77ms。数字只代表当时开发样机与场景，不是屏幕帧率或长期稳定性承诺。419帧均匀白墙回放没有画出轮廓，但这不能表示真实目标轮廓准确率。

公开版本将字体换成SIL OFL的Noto字形重新编译，因此UF2与本地实机版不同。公开二进制未额外刷机验收；实拍同一约51°C目标的改善幅度尚未完成核对，不能标记为画质已验收。弱温差、小目标或全屏目标可能无轮廓。

固件264MHz/O3，不提高电压；不同板卡应单独适配。原250MHz公开包保留在旧Release。下载UF2后使用随包SHA256SUMS和manifest.json核验，刷写与恢复见[恢复指南](RESTORE.md)。

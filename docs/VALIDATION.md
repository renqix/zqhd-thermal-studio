# 第12版公开构建验证

2026-10-11，v12.0.0-public.1，Noto Sans SC公开字形构建。

- Arduino-Pico3.9.5 / LVGL8.3.11 / TFT_eSPI2.5.43，264MHz/O3编译通过。
- Flash516448字节，静态RAM227436字节，剩余34708字节供栈和堆使用；编译器提示剩余内存较低，未验证长期稳定性。
- 10项C++测试通过地址与未定义行为检测：按钮、映射轮廓、内部纹理及孔洞、布局、OneEuro参考、色板、处理、Tiny、跟踪、UI。
- 3项Python网页测试通过：本机与令牌校验、原始输入不变、轮廓及背景降噪参数边界。有效参数采用模拟发送，不视为实机确认。
- 网页JavaScript语法、Python语法和Git差异格式检查通过。
- 当前INT8模型文件与固件权重逐项一致；全部菜单所需汉字包含在开源字体子集中，字形预览已检查。
- 文本和UF2未检出开发者个人路径、固定设备序列号或系统字体。个人实拍、真实原始采样与整片备份不在发布中。
- 公开二进制未额外刷机；本地系统字体版的短时实机检查见RELEASE-12.md。两者不能混称为同一二进制。
